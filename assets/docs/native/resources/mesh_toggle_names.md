# Mesh toggle names

Names for the `MeshToggleIndex` enum entries. These correspond to
game areas / world objects that the engine can toggle visible /
hidden via the mesh visibility system.

Source: `mods/main_overlay/.../yorha_protocol/data/mesh_toggle_names.dart`.

These are world-mesh toggle indices, not the per-character mesh node
names you'd put in `[[mesh_override]].mesh`. For per-character mesh
node names see the **Common meshes** tables in
[05_outfit.md](../05_outfit.md), [06_accessory.md](../06_accessory.md),
and [11_special_effects.md](../11_special_effects.md), which list the
typical body / hair / eyemask node names you use in a
`[[mesh_override]]` block.

The 62 toggle indices below are the world-side toggles that map to
specific world meshes (factory pieces, walls, props, etc.).
